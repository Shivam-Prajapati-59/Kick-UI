The `WaveCarouselItem` shape: `image` (tile image URL), `title` (the link's `aria-label`, or the image's alt text when there is no `href`), `href` (renders the tile as a link), `fit` (`"cover"` default or `"contain"` for logos at ~58% size), `background` (CSS colour behind the image, defaults to the `bg-card` token), and `pixelated` (keeps pixel art crisp when the tile scales).

Motion: two rows drift in opposite directions in an endless loop, with a travelling sine wave modulating each tile's vertical offset. Each tile carries a blurred copy of its image, tinted by its `background`, behind the face as an ambient glow. Dragging scrubs both rows with decaying inertia. Hover or focus lifts and slightly enlarges the tile, scales the image, and brightens the glow. An entrance animation runs once on first view. All motion respects `prefers-reduced-motion`. The root has no background of its own, so the section blends into the page it sits on. It fills its container; give it around 800px of height on desktop (640px on phones) so the rippling rows clear the centred text.

Accessibility: tiles are links when `href` is set, otherwise divs; duplicated loop copies are `aria-hidden` with `tabIndex={-1}` so each item is announced once. Plain images use lazy loading and async decoding. The heading's full text is exposed via `aria-label` while per-word spans are `aria-hidden`.

Install note: the component is a single `wave-carousel.tsx` file.
