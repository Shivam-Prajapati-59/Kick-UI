The `HolderTestimonial` shape: `name` (ENS or display name), `address` (full wallet address, shown truncated and copied on click), `quote` (testimonial body), and the optional `role`, `avatar` (image URL; the holder's initials are used when missing or it fails to load), `chain` (network name), `holding` (`{ amount, symbol }` holder chip), `verified` (shows a verified badge), `since` (shown as "Since <value>"), and `bg` / `text` (hex overrides for the tab colours). By default the colours come from `chain`: a muted take on each network's brand hue (Ethereum, Base, Arc, Bitcoin, Solana; `eth`, `btc` and `sol` work as aliases) with text that keeps 7:1 contrast or better, and a neutral sand for unknown chains. The map is exported as `chainPalettes`.

Accessibility: the component is a `tablist` with `tab` elements; arrow keys move between tabs (Up/Down in vertical mode), Enter/Space selects, and only the active tab is in the tab order. The address copy button is a real button with keyboard support and announces "Copied" through an aria-live region. The copy button stops propagation so it does not re-select its tab.

Motion: hover grows collapsed tabs from 354px to 366px in horizontal mode. With reduced motion enabled all transitions become instant. The component switches between horizontal and vertical layouts below 560px automatically.

Install note: the component is a single `holder-testimonials.tsx` file.
