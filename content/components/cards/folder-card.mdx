    return (

props:
  - name: number
    type: string
    description: Big number shown on the folder front.
  - name: title
    type: string
    description: Title shown at the bottom of the card.
  - name: description
    type: string
    description: Description shown under the title. Does not move on hover.
  - name: image
    type: "{ src: string; alt?: string }"
    description: Image that rises out of the folder on hover. Rendered with a plain img element.
  - name: href
    type: string

  - name: folderColor

  - name: foreground
    type: string

  - name: className

---

On hover (or focus, for the link variant) the folder front slides down, the image rises up from behind it, and the arrow rotates 45 degrees. The title and description stay put.

The background defaults to a primary-to-background gradient; pass any CSS background value (including multi-layer radial gradients) for a richer look. Frame, folder and foreground colors are applied through CSS custom properties, so they can be any CSS color and they inherit correctly inside the card.

Reduced motion is honored through MotionConfig, which disables the transform animations without a hydration mismatch. Fonts are never set by the component; it inherits the host app's fonts.
